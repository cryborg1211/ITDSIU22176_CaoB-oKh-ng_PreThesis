# report/

Thesis source (English, IU SCSE format reconstructed from past theses).

| File | Purpose |
|---|---|
| `main.tex` | entry point: metadata (title, name, ID, supervisor, date) + chapter order |
| `iuthesis.sty` | layout: A4, margins, 1.5 spacing, cover, committee page |
| `frontmatter/` | acknowledgements, abstract, abbreviations (acronyms) |
| `chapters/` | 01 intro ... 07 conclusion, skeleton from `docs/00-scope-synthesis.md` |
| `appendices/` | VN market rules table |
| `references.bib` | BibTeX (natbib, numeric) |
| `figures/` | figures generated by code; optional `iu-logo.png` appears on the cover |

Build (any one):

- `tectonic main.tex` (single binary, fetches packages itself)
- `latexmk -pdf main.tex` (TeX Live / MiKTeX)
- Overleaf: upload this folder, compiler pdfLaTeX

For the pre-thesis milestone set `\documentkind{pre-thesis report}` in `main.tex`.
Check margins / spacing against the current SCSE guideline before submitting.
